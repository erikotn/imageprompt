# Advanced Prompt Architect

Bouw scherpe prompts voor AI-beeldgeneratie via een formulier in plaats van vanuit je hoofd. Helpt je consistent dezelfde structuur te gebruiken: kernonderwerp → stijl → compositie → lichtsetting → camera.

**👉 [Open de tool](https://erikotn.github.io/imageprompt/)**

## Wat het doet

- Vul kernonderwerp in (bijv. "een man die een neon-sigaar rookt in een futuristische bar")
- Kies stijl, medium, compositie, lichtsetting, camera-instellingen via dropdowns
- Tool zet alles om naar een gestructureerde prompt die je kunt kopiëren naar Midjourney, DALL·E, Stable Diffusion, Flux, etc.

## Voor wie

Designers en strategen die regelmatig AI-beelden maken en consistente kwaliteit willen zonder iedere keer een prompt-formule uit het geheugen te trekken.
